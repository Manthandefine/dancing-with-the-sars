DESCRIPTION:
Dancing on the SARs is an AI-powered Earth observation platform using NASA-ISRO NISAR and L-band SAR data to detect floods, monitor deforestation, analyse Earth's surface changes, and support disaster management, evacuation planning, and relief operations.
